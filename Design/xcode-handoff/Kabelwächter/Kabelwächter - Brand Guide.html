01

Brand essence

What the design communicates
Voice

Precise, technical, calm. We name things by what they are. No exclamation marks, no fluff. Telemetry over copy.

Form

Concentric tunnel rings, perspective rays, fine grids, scan lines. Bright signal cores on deep navy. Mono type carries authority.

Feel

A radar console at 03:00. Quiet, alert, glowing. The interface watches the wire so you don't have to.

extension Color {
    init(hex: UInt, opacity: Double = 1.0) {
        self.init(
            .sRGB,
            red:   Double((hex >> 16) & 0xFF) / 255,
            green: Double((hex >> 8)  & 0xFF) / 255,
            blue:  Double( hex        & 0xFF) / 255,
            opacity: opacity
        )
    }
}

Typography

SF Mono · SF Pro Text

Mono carries the brand. SF Mono ships with every Apple OS and is the production typeface in Xcode — JetBrains Mono is the web mirror. Use sans (SF Pro Text) only for long-form body copy where mono would tire the eye.

08

Do & don't

Brand guardrails
DO
  • Place the tunnel mark on deep navy — let the core glow read as the brightest point in the frame.
  • Use mono for any number, status, identifier, or label. Always.
  • Reserve #00FF9D exclusively for the "connected / live" state.
  • Keep generous negative space. The interface should breathe like a console.
  • Anchor key surfaces with corner brackets — they signal "selected" without filling space.
DON'T
  • Use signal green as decoration — it must always mean "connected".
  • Apply gradients beyond the core radial glow. No purple→pink, no cyber clichés.
  • Mix rounded-soft corners or drop shadows into chrome — flat hairlines only.
  • Use sans-serif for status, telemetry, or identifiers. Mono is the brand voice.
  • Recolor the app icon or place it on a non-square canvas. Always export from the master SVG.

Setup checklist
  1. Drag icon-1024.svg into an AppIcon.appiconset — export PNG at each required size, or let Xcode 14+ scale from the single 1024.
  2. For tvOS, create an imagestack with three imagestacklayer folders. Drop icon-tvos-back.svg → Back, …-middle.svg → Middle, …-front.svg → Front.
  3. Add Color+Kabelwaechter.swift and Font+Kabelwaechter.swift to a Theme group.
  4. Set UIUserInterfaceStyle = Dark in Info.plist — the brand is dark-only.
  5. Use SF Mono via .monospaced design — no font file shipping required.
  6. Reference WireGuard kit via NetworkExtension · NEPacketTunnelProvider.
Example · Connect button (SwiftUI) Copy 
struct KWConnectButton: View {
    let isConnected: Bool
    let action: () -> Void

    var body: some View {
        Button(action: action) {
            HStack(spacing: 10) {
                Image(systemName: isConnected ? "bolt.slash.fill" : "bolt.fill")
                Text(isConnected ? "DISCONNECT" : "CONNECT")
                    .tracking(2.2)
            }
            .font(.kwLabel.weight(.semibold))
            .padding(.horizontal, 22).padding(.vertical, 14)
            .foregroundStyle(Color.kwBg0)
            .background(isConnected ? Color.kwError : Color.kwSignal)
            .shadow(color: (isConnected ? Color.kwError : Color.kwSignal).opacity(0.45),
                    radius: 18)
        }
        .buttonStyle(.plain)
    }
}
